# 舊帳本放這裡

過去幾個月的月度 Excel，直接拖進這個資料夾就好，檔名不用改。

一個月一個檔、五個分頁那種。放幾個月都可以，一次全部放進來也行。

## 放進來之後

在專案資料夾開終端機，跑：

```
npm run check:excel
```

它只**讀**檔案，不會改你的 Excel、也不會寫進資料庫。跑完會印出每個分頁長什麼樣子、
哪一欄是日期、哪一欄是金額、有哪些分類名稱。把這段輸出貼給 Claude，就能對出匯入規則。

## 幾件事

- **只吃 `.xlsx`**。如果是舊的 `.xls`（Excel 2003 那種），用 Excel 開起來另存成
  「Excel 活頁簿 (\*.xlsx)」再放進來。
- 檔案在 Excel 裡開著也沒關係，檢查程式會跳過 `~$` 開頭的暫存檔。
- **這個資料夾裡的 Excel 不會進 git**（`.gitignore` 擋掉了），只留在你自己的電腦上。
  裡面是真實的收支數字，不該推到 GitHub。
- 匯入完成之後這些檔案可以留著當備份，系統不會再讀它們。
